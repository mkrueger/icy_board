# Door drop-file specifications

These documents describe the files currently generated by Icy Board's
`DropFile` implementations. They are implementation specifications: fixed
values and compatibility quirks are recorded as emitted, even where a legacy
format permits other values.

Text files are written with CRLF line endings. Dynamic Rust strings are UTF-8;
binary fixed-width strings are encoded as CP437 and padded as noted. Integer
fields in binary files are little-endian.
