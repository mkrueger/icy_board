# Hilfe: (NEWS) anzeigen

Dieser Befehle zeigt die Neuigkeiten der aktuellen Konferenz an.

## Beschreibung

Neuigkeiten enthalten üblicherweise neue Informationen oder Events die BBS
betreffend. Die Neuigkeiten werden beim Logon oder Konferenzwechsel
angezeigt. Mit diesem Kommando kann das jederzeit passieren.
