# Hilfe: (WHO) Wer ist online

Dieser Befehl zeigt eine liste der eingeloggten Benutzer an.

## Beschreibung

Die meisten user interessieren sich dafuer, wer grade eingeloggt ist.
Dafuer ist das WHO Kommando. Wenn man es ausfuehrt zeigt IcyBoard eine
Liste der im augenblick eingeloggten Benutzer an.

## Beispiel

```text
(#)   Status                  User
---   ---------------------   -----------------------------
  1   Out of Code in DOOR     JOE
  2   Available for CHAT      SYSOP
  3   Available for CHAT      ASHLEY
```

Im obigen Beispiel sieht man einen Nutzer in Node 1 der ein Door ausfuehrt.
In 2+3 Benutzer sind eingloggt sind und evtl. in einem Menue sind und die
fuer einen Chat verfuegbar sind.
