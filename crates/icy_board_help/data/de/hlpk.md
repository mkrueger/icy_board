# Hilfe: (K) Nachricht löschen

Dieser Befehl markiert eine Nachricht als inaktiv und unlesbar. Diese ist
physisch noch vorhanden und wird beim nächsten Aufräumen gelöscht.

## Subkommandos

- `[Nachricht #|` Die Nachricht die gelöscht werden soll.

## Beschreibung

Mit dem Befehl können Nachrichten gelöscht werden. Es gibt 2 Prompts wo
Nachrichten gelöscht werden können. Message Lesen und das Hauptmenü.

RECEIVER ONLY kann nur vom Sender und Empfänger gelöscht werden.
SENDER PWD kann nur vom Sender gelöscht werden.
GROUP PWD kann nur mit Passwort gelöscht werden.
Der Sysop kann alle Nachrichten löschen.

## Beispiel

Befehl, um die Nachricht '42' zu löschen:

```text
K 42
```
