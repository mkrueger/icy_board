# Hilfe: (P) Seitenlänge setzen

Dieser Befehl ändert die Zeilenzahl die IcyBoard auf dem Bildschirm vermutet.

## Unterkommandos

- `[# Zeilen]` Die Anzahl der angezeigten Bildschirmzeilen (0-99).

## Beschreibung

Dieser Befehl gibt die Zeilenanzahl an die IcyBoard anzeigt zwischen den
mehr? Prompts. Normalerweise sind es 23 Zeilen, aber alles zwischen 0 und
99 ist gültig. 0 deaktiviert den mehr? Prompt.
