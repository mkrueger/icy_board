# Help: Group Chat and Commands

This prompt allows you to execute chat related commands. To exit the
command prompt just press ENTER.

## Commands

- `CALL` Call user to chat.
- `CHANNEL` Change current channel.
- `ECHO` Enable echo mode.
- `G/BYE` Logoff
- `HANDLE` Change handle.
- `IGNORE` Ignore input from one or more nodes.
- `MENU` Display chat menu.
- `MONITOR` Toggle monitoring of public channels.
- `NOECHO` Disable echo mode.
- `PRIVATE` Make channel private.
- `PUBLIC` Make channel public.
- `Q` Exit chat mode.
- `SEND` Send private message.
- `SHOW` Show users currently chatting.
- `SILENT` Toggle silent mode.
- `TOPIC` Change current topic.
- `WHO` Show who is currently online.
- `X` Toggle expert mode.
