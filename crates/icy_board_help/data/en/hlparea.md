# Help: (AREA) Change

Messages in conferences are grouped by area. By dividing messages into
categories it's easier to follow discussions.

## Subcommands

- `[area name]` Area name to join. Specifies the message area name you
  wish to join.
- `[area num.]` Area number to join. Specifies the message area number you
  wish to join.
- `S` Search area names for text. Filter areas to join for a text
