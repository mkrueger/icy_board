# Help: (WHO) is Online

This command enables you to see who is currently online.

## Description

Most users like to know who else is currently on the system.
That's what the WHO command is the answer for.
When executed, IcyBoard displays the users currently online on the system.

## Example

```text
(#)   Status                  User
---   ---------------------   -----------------------------
  1   Out of Code in DOOR     JOE
  2   Available for CHAT      SYSOP
  3   Available for CHAT      ASHLEY
```

From the above example display we can see that the user on node 1 is
currently running a door. The users on node 2 and 3 are logged on and
probably browsing menus and are available for chat.
