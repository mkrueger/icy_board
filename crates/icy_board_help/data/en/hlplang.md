# Help: (LANG)uage Change

IcyBoard has the ability to support multiple languages. This command lets you
select your board system language.

## Subcommands

- `[language #]` The language number you wish to use. If no number is given
  an available language list to choose from is displayed.

## Example

To change to language number 2. Enter the following:

```text
LANG 2
```
