# Help: (B)ulletins

Bulletins display infomations, ruls etc. for the bbs.

## Subcommands

- `(bulletin #)` Bulletin number. Display bulletin number. You can specify
  several bulletin numbers.
- `A` All bulletins. List all bulletins.
- `D` Download bulletins. Download bulletin instead of viewing it
- `N` New bulletins. Display only new/updated bulletins.
- `NS` Display in nonstop mode. Display without more prompt.
- `R` Re-display menu. Redisplay the bulletin menu.
- `S` Search bulletins for text. Search bulletins for text.

## Description

A bulletin is a file that contains important information about the bbs.

## Examples

To view bulletin 2 on a system type:

```text
B 2
```
