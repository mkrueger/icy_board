# Help: (P)age Length Setting

Allows you to change the number of lines that IcyBoard should think is on
your display screen.

## Subcommands

- `[# lines]` The number of lines displayed on the screen (0-99).

## Description

This command specfies the number of lines IcyBoard displays between the
more prompts. Usually it's 23 but every value between 0 and 99 is valid.
Setting this to 0 disables the more prompt.
