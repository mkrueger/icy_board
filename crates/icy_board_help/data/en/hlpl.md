# Help: (L)ocate a Filename

This command searches for filenames in the file directories. Wildcards are
permitted.

## Subcommands

- `#` Directory number to search. Icy Board scans for the text in
  this directory. You may specify a range #-# or a list of
  diretory numbers.
- `[PATTERN]` Filename to search for. Wildcards are permitted
- `D` Flag each found file for download.
- `N` Include the minimum file date from which the scan should
  search for.
- `NS` Use Nonstop mode for screen output.
