# Help: (USER) Listing

This command allows you to search the user file for a text string.
IcyBoard will display all matching records.

## Subcommand

- `(text)` Text to search for.

## Description

This command displays the user name, location and last on date of all
matching users.

## Example

If you wanted to find everyone from Berlin search all user records for
the word 'Berlin':

```text
USER BERLIN
```

At this point you will may see the following on your screen:

```text
        User Name                  Location              Last On
-------------------------  ------------------------  ---------------
OMNIBRAIN                  BERLIN                    06-13-24 13:37
SYSOP                      BERLIN                    07-23-24 21:12
BERLIN JOE                 ZOSSEN                    12-13-23 14:21
```
