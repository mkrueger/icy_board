# Help: (CHAT) Group Chat

This command allows you to chat with other users that are currently
online in this BBS.

## Subcommands

- `A` Available for chat. By default you are available for chat
  by marking unavailable no one can invite you to chat.
  This setting is preserved.
- `G` Group chat. This subcommant begins chattings with other
  users on the system.
- `U` Unavailable. When using that command you're marked not
  available for chat. Other users may not call you into
  group chat.
