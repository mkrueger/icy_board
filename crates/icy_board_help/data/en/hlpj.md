# Help: (J)oin a Conference

Conferences is the way to separate information, messages and files. By
dividing that up in categories you can find things faster.

## Subcommands

- `[conf. name]` Conference name to join. Specifies the conference
  name you wish to join.
- `[conf. num.]` Conference number to join. Specifies the conference
  number you wish to join.
- `Q` Quick-join the conference. If the the conference to join
  has news or introduction file these will be skipped.
- `S` Search conference names for text. Filter conferences
  to join for a text.

## Description

Conferences provide a method which information on the bulletin board
system can be broken down into areas. Each conference can have unique
file directories, message bases, scripts, bulletins, and doors, or it
may share any of these with other conferences on the system.

## Examples

To join conference with number 13, enter the following at the command
prompt:

```text
J 13
```

If you know the name of the conference it can be used instead of the
number. For example to join the 'BBS' conference then type:

```text
J BBS
```

If you do not know either the conference name or the conference number,
use the search subcommand to help you find the right conference.
For example to join a conference that contains 'GAMES' type:

```text
J S GAMES
```

IcyBoard will search the conference names to see if it could find a
match. For example you may see a prompt like that:

```text
1) PC Games
12) Amiga Games
42) C64 Games
```

Pick the conference with the number.
