# Help: (V)iew Settings

This command allows you to view information and stats for the current
session.

Page Length: 23
Expert Mode: Off
Security Lv: 110
# Downloads: 123
# Uploads  : 456
Tr/Protocol: ZModem
 Alias Mode: Off
   Gfx Mode: Graphics
