# Help: (O)perator Page

This command is used to page the SysoOp for chat. If the SysOp isn't
available you can leave a comment.

## Description

This command enables you to request a chat with the SysOp. It'll beep for
30 seconds until the page is answered. If the SysOp doesn't answer or is
unavailable IcyBoard will ask you to leave a comment instead.
