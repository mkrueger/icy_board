# Help: (F)ile Directories

This command lists files in the current conference and finds a file by name
or text search in the file description.

## Subcommands

- `L` Locate filename(s). Displays onle files which match a particular
  filename. Wildcards can be used (? and *).
- `N` Display files after a particular date. You can specifiy another date
  by stacking the date after the N subcommand or set the default date
  by the S command.
- `Z` Search entire file listing for text. You may filter the listed files
  with a pattern for more complex searching.
- `#` File directory number. Specify a file directory number you want to
  view. If you want to view multiple file directories enter each
  directory number separated by either a SPACE or a SEMICOLON. r
- `U` View public upload directory. This view the public upload directory.
- `P` View private upload directory. (sysop level only)
- `D` Flag the files found for download. Flags all files on screen for
  download. No warning is given if batch limit es exceeded.
- `F(LAG)` Flag a file to download by file name. Flags a single file by
  filename. Wildcards can be used.
- `G` Disconnect from the system.
- `NS` Display listing in non stop mode.
- `R` Re-display available file directories. This subcommand will refresh
  the list of file directories that are available in the current
  conference.
- `V` View a file. Sometimes more file information about a file is
  required. With this subcommand file contents can be seen.

## Descriptuon

File transfer is the most popular attraciton to bbs systems. You may wish
to view a list of files that are on the system to see if there are files
that they whish to download or to make sure that a particular file is
not already available.
