# Help: (H) Online Help

This command lets you show the online help. This provides help for all
available commands.

## Subcommands

- `[command]` The command to view the help for.

## Description

All IcyBoard main menu commands have an online help. This command is used
to access that.

## Examples

To view the help for the 'C' command type:

```text
H C
```
